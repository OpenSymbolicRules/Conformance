## [Unreleased]

### Added
- Rewrite conformance suite format (`schemas/cases.schema.json`).
- `trigonometry` suite: 84 cases generated by the Lean reference rewriter,
  with the rule set they were generated from.
- Digest consistency check, `justfile` and CI.
- `calculus` suite: 65 cases (derivatives and two-sided limits of lambda
  terms).
- `logic` suite: cases in the boolean domain, including quantifiers
  (`OMBIND`); the case schema accepts the `boolean` domain and `OMBIND`.
- `algebra` suite: 56 cases, including inputs where only conditional rules
  match (the reference engine leaves them unchanged).

### Changed
- Refresh the generated OSR v1 files from Lean source digest `4032322e…`
  after the structural Calculus premise audit; rule statements and
  certification counts are unchanged.
- `trigonometry` suite regenerated from Lean source digest `a6649bd5…`;
  the cases are unchanged.
