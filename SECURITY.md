# Security Policy

## Supported Versions

| Version | Supported |
| ------- | --------- |
| 0.1.x (pilot) | :white_check_mark: |

## Reporting a Vulnerability

Please report security vulnerabilities, including a suite that does not match
the Lean reference rewriter or the rule set it names, through a
GitHub Security Advisory (GHSA) on this repository:
<https://github.com/OpenSymbolicRules/Conformance/security/advisories/new>.

Do not open public issues for security vulnerabilities.
